## Problem 1: Reverse a Number (Without Using String Type)

### Objective
Write a JavaScript function that takes an integer as input and returns its digits reversed — using **only mathematical operations**. No strings, no arrays, no built-in methods.

### Instructions
- Accept a positive integer as input
- Use **arithmetic operators only**: `%` (modulus), `Math.floor()`, and basic operators `*`, `+`
- Extract digits one by one using the remainder and division technique
- Build the reversed number mathematically
- Return the result as a number


## Problem 2: Generate a Random Integer Between 1 and 100

### Objective
Write a JavaScript function that uses `Math.random()` to generate and return a random integer between **1 and 100** (both inclusive).

### Instructions
- Use the built-in `Math.random()` method
- The result must always be a whole number (integer)
- The range must be **inclusive** of both 1 and 100
- Call the function multiple times and log the results to verify randomness
